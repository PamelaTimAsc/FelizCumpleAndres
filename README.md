# Feliz Cumpleaños - Carta Interactiva

¡Una hermosa y romántica carta de cumpleaños interactiva con animaciones, música y sorpresas!

## Características

- 💌 Pantalla de bienvenida con botón interactivo
- ✨ Efecto de máquina de escribir para el mensaje de cumpleaños
- 🎵 Música de fondo suave
- 📸 Botón para mostrar una foto especial
- 💌 Botón para mostrar un mensaje especial
- 🎊 Animación de confeti al revelar el mensaje especial
- 📱 Diseño completamente responsivo para móviles y escritorio

## Cómo Usar

1. Clona o descarga este repositorio en tu computadora.
2. Prepara los siguientes archivos:
   - Una foto especial (opcional) - nómbrala `birthday-photo.jpg` y colócala en la misma carpeta
   - Una canción de fondo (opcional) - nómbrala `happy-birthday.mp3` y colócala en la misma carpeta
3. Abre el archivo `index.html` en tu navegador web favorito.
4. ¡Disfruta de la experiencia interactiva!

## Personalización

Puedes personalizar fácilmente la carta:

1. **Mensaje de cumpleaños**: Edita la variable `birthdayMessage` en el archivo `script.js`
2. **Estilos**: Modifica los colores y fuentes en el archivo `styles.css`
3. **Foto**: Reemplaza `birthday-photo.jpg` con tu propia imagen
4. **Música**: Reemplaza `happy-birthday.mp3` con tu canción favorita

## Requisitos del Navegador

- Cualquier navegador web moderno (Chrome, Firefox, Safari, Edge)
- Se recomienda la última versión para la mejor experiencia

## Notas

- La música se reproducirá automáticamente al abrir la carta (solo después de la interacción del usuario)
- La experiencia es mejor en dispositivos con pantalla táctil
- ¡Diviértete personalizándola para hacerla única!
